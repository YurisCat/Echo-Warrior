## 已确认或高概率为 BUG

| 用例 | 判断 | 依据与影响 | 处理范围 |
| --- | --- | --- | --- |
| EW-077 | 已确认 BUG | 知识书返还使用了普通背包插入后再检查剩余数量。创造模式满背包时，原版插入逻辑会把待返还物品数量清零，导致既没有进入背包，也没有掉落。违反“背包满时掉在玩家脚下”的项目约定。 | 改用原版“放回背包，否则掉落”流程。 |
| EW-101 / EW-102 / EW-103 | 高概率同一 BUG | 创造模式物品栏直接把饰品、护符或模块塞进召唤器时，客户端会更新物品，但服务端只收到创造栏位同步包，没有执行召唤器正常点击路径中的绑定状态提交。随后权威绑定数据把召唤器覆盖回旧状态，而鼠标上的物品已经减少，表现为吞物。 | 在服务端接受创造模式栏位更新后，若栏位物品是召唤器，立即提交其物理组件状态并同步已绑定英灵。 |
| EW-180 | 已确认 BUG | 埃及弓箭手使用独立跟随逻辑，超过距离后直接传送到主人当前 Y 坐标，没有验证脚下是否可站立。玩家在空中时会把弓箭手传进空气。 | 所有英灵召回和远距跟随统一只使用安全落点。 |
| 创造飞行高空抽搐/闪现 | 已确认与 EW-180 同类 BUG | 埃及弓箭手会在高空被反复传送、下落，再次超过阈值后又传回；其他英灵在主人悬空且没有可达落点时仍持续寻路或尝试传送，也可能出现位置抖动和不必要的路径计算。 | 主人明显悬空时停止向空气寻路；若英灵已在主人下方附近，则稳定等待；水平距离过远时最多按节流频率寻找主人投影附近的地表安全落点。 |
| 召唤器 GUI 英文缺失 | 已确认 BUG（开发自查） | 语言文件中虽然已有技能英文，但英雄名、属性提示、行动/警戒模式、经验、燃料、按钮及反馈文字大多直接硬编码为中文，切换英文后仍显示中文。埃及弓手的警戒范围提示还固定写成 16 格，与界面数值 24 格不一致。 | 全部改为中英文语言键；英文采用精简按钮与说明；标题、分区标题和按钮仅在实际超宽时等比缩小；警戒范围提示读取英雄实际范围。 |
| 日本武士表情系统缺失 | 已确认 BUG（开发自查） | 日本模型已经具备 `Head`、左右眼与 `Eyebrow` 骨骼，但实体没有同步注视、眨眼、对视及被发现偷看状态，渲染器也没有消费这些骨骼，导致第五位英灵明显缺少其他英灵已有的视觉生命感。 | 复用中国关刀战士的服务端视觉状态机，并增加日本模型专用客户端骨骼映射；战斗动作保留原动画骨骼优先级，残影只冻结最终姿势。 |

## 当前较可能不是独立 BUG

| 用例 | 判断 | 理由 |
| --- | --- | --- |
| EW-100 | 更像测试方法与交互路径不一致 | 该项需要区分正常点击交互与创造模式物品栏直接编辑；不能把没有触发物品钩子的操作直接判成正常交互失效。 |
| EW-115 / EW-119 | 暂不视为独立 BUG | 依赖 EW-101～103 的直接塞入成功。上游吞物会使后续饰品/护符效果无法进入有效测试状态，修复上游后应回归。 |
| EW-168 | 部分为预期行为，部分并入 EW-180 | 主人死亡或旁观时其他英灵不继续普通跟随符合当前控制边界；其中弓箭手的异常传送属于 EW-180 同类问题。 |
| EW-173 | 防御逻辑看起来已生效 | 日志中的重复召唤器 UUID 警告随后执行了 UUID 重分配，说明复制检测在工作。两个不同绑定的英灵同时存在本身允许，不能仅凭“出现两个英灵”判错。 |
| EW-220 | 更像触发条件或搭建方式不匹配 | EW-216 已通过直接边界触发，说明基础触发链路存在；应先复核 EW-220 的距离、目标状态和环境条件。 |
| EW-292 | 与设计预期不一致 | 召唤器内部安装的遗物不参与普通掉落物回收；该用例也没有真正形成可衡量的性能场景。建议调整测试预期，而不是修改回收规则。 |

## 运行日志观察

- 没有发现与上述失败用例直接对应的崩溃、异常堆栈或模组致命错误。
- 多次 `large_dripstone` 在远处未加载区块写方块失败，来源更像原版环境/世界生成行为，不足以指向 Echo Warrior。
- Realms、用户属性请求错误属于网络或账号环境噪声。
- JEI 对可选 Amecs 兼容项的提示不是本模组功能故障。
- 重复召唤器 UUID 警告出现多次，但随后有重分配行为；当前应视为防御性修复记录，而非崩溃问题。
- `latest.log` 约 5.2 MB、覆盖约两小时，包含大量动画与骨骼相关 INFO 输出。它未直接造成这批功能失败，但属于发布质量和潜在性能风险：正式交付前应降低为 DEBUG、增加采样/节流或移除逐帧日志。

## 游戏内人工回归清单

1. EW-077：分别在生存和创造模式填满主物品栏，再从知识合集提取一页；确认知识书掉在脚下而不是消失。
2. EW-101～103：在创造模式物品栏中直接向召唤器放入燃料、遗物和三类兼容饰品；确认鼠标物品只减少正确数量，关闭并重新打开界面后内容仍存在。
3. EW-101～103 已召唤状态：英灵在场时直接更换或安装饰品，确认服务端效果立即更新，并在重新登录后仍与召唤器一致。
4. EW-180 地面远距：五种英灵分别与主人拉开超过 32 格，确认只落到可站立、无碰撞的位置。
5. 高空垂直悬停：召唤英灵后原地创造飞行升至远高于 32 格，至少观察 30 秒；确认英灵留在下方稳定位置，不反复传送、坠落或抽搐。
6. 高空水平移动：在高空横向飞出英灵下方约 12 格以上，确认英灵至多周期性寻找主人投影附近的地表安全落点，抵达后继续稳定等待。
7. 高空手动召回：在高空潜行右键召回；有地表安全落点时英灵到达地面，无安全落点时保持原位且不出现传送粒子或坠落循环。
8. 洞穴、下界与末地边缘：确认安全传送不会把英灵送入方块、岩浆、下界基岩顶层或末地虚空。
9. 英文界面：将语言切换为 English (US)，依次检查五种英灵、无遗物/已召唤/未召唤三种按钮状态、全部属性与模式悬浮提示、经验、燃料、饰品槽和各类操作反馈；确认没有中文残留、翻译键原样显示或文字越界。
10. 日本武士自然神情：清空附近敌人并保持站立或普通行走，观察自然／双重眨眼、偶发歪头、头部与左右瞳孔独立追踪；行走时应主要看向前进方向。
11. 日本武士对视与回避：持续盯住武士头部直至完成对视，重复测试主人先被偷看再回看的分支；确认瞳孔先移、头部后跟、身体平滑转向，回避离场不会刚走开又立刻回头。
12. 日本武士动作冲突：在普通攻击、刺、踏込、真实后撤与受伤动作前后反复触发对视或眨眼；确认动作期间没有头部／眉毛抽动，动作结束后眼神平滑恢复，战斗与受伤能立刻中断社交状态。
13. 日本武士残影冲突：分别触发踏込残影、真实后撤残影和完整动作中的幻影闪避；确认每道残影保持生成当刻的固定眼神与头部姿势，不会在消散过程中继续眨眼、转头或改变瞳孔大小。
