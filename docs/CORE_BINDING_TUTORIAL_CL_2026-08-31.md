# 核心绑定、教程手册与军团兵平衡 CL（2026-08-31）

本次版本把召唤器与英灵的关系改为服务端持久绑定，补齐游戏内教程手册，并完成罗马军团兵的首轮防御与反制平衡。相关运行时资源、人工源文件、百科内容和测试清单已同步纳入版本库。

## 核心绑定与召唤器

- 召唤器 UUID、内部燃料、遗物、饰品、成长数据、控制者和存活英灵状态统一由服务端 SavedData 管理；物品栈作为可同步镜像。
- 英灵不再因旧持续时间结束、控制者离线或控制者死亡而自动消散。主动遣散、英灵死亡、移除遗物、确认销毁召唤器或管理员终止绑定时才结束。
- 跟随模式可随控制者跨维度安全重建；等待和闲逛模式保留在原维度，不强制加载区块。
- 召唤器放入箱子、潜影盒、收纳袋或成为掉落物后仍保留绑定，英灵击杀经验仍可写回权威遗物。
- 检测同 UUID 复制品时保留先登记的原件，副本获得新 UUID 且不继承原英灵控制权。
- 增加并发菜单修订校验、召唤数量配置与性能提醒，以及 `/echo_warrior binding` 管理员诊断、遣散和修复命令。
- 新增物品与嵌套容器销毁检测；仅在确认召唤器实际被销毁时终止绑定，未知模组容器优先避免误杀。
- 正式加入测试英灵召唤器合成表。

## 教程手册《回声、战士与你》

- 新增不可堆叠的 `tutorial_manual` 物品、合成表、创造模式入口、服务端菜单和客户端阅读界面。
- 手册共 44 页，覆盖探索与考古、五名英灵、25 件饰品、配方、制作名单和知识来源。
- 支持章节标签、前后翻页、配方附件、技能说明、物品悬浮提示和页内跳转，并在物品数据中保存上次阅读页。
- 中文保持默认字号；英文标题和正文仅在超出安全区域时自动缩放，避免截断。
- 加入人工制作的 GUI、头像和物品图标源文件，以及可重复导出运行时资源的脚本。

## 罗马军团兵

- 新增第二技能“军团壁垒”：来自身体前方 180° 的直接攻击和投射物伤害在护甲结算后降低 50%。
- 条件二连击第二击由 50% 提高为 75%，其他判定距离、时机和追步规则保持不变。
- 举盾冲锋改用连续轨迹检测高速投射物；反弹优先瞄准原射手，其次寻找附近敌人，否则向远离主人的方向弹开。
- 潜影弹等追踪投射物会同步更换或清除目标，不会转弯继续追击主人。
- 撞击蓄爆苦力怕造成当前攻击力 200% 的普通伤害，并短暂清除目标和压低自然蓄爆进度。
- 罗马技能顺序升级为“士兵阵列、军团壁垒、举盾冲锋、军团永存”，旧遗物技能开关按技能身份迁移，不串位。
- 士兵阵列及其他永久光环增加距离滞回和服务端反向审计，避免效果闪烁、重复叠加或永久属性残留。
