## 更新内容与边界

- 协助战斗增加关闭／保护／全部，保护为默认；涵盖已确认的村民、铁傀儡和已驯服生物名单。
- 技能成长、阿兹特克诅咒与增距、关刀前三段小浮空及隐藏缩距。
- 指定饰品攻击／生命百分比、最大生命相关治疗。
- 当前值简版、按住 Alt 展开公式、GUI 更新、完整本地化及长饰品提示换行。
- 现有世界可继续使用；更新后重启客户端和服务器，无需新世界或新区块。同一加载器只保留一个 Echo Warrior JAR。
- 不包含其他玩家英灵保护选项、通用装备栏、新角色或 26.3 支持。关刀浮空和阿兹特克距离后续仍可由作者调参，不宣称所有战斗手感或第三方整合包均已验收。
