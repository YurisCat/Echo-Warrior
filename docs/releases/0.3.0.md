# Echo Warrior 0.3.0 发布与验收记录

日期：2026-11-13，Asia/Shanghai。状态：**发布准备中，尚未上传。**

作者在完成技能、饰品、协助战斗及本地化更新后，明确选定 `0.3.0` 并授权发布到 CF 等既有平台。本轮按既定流程覆盖 CurseForge、Modrinth 与 GitHub Release；三个 Minecraft 版本、六个加载器包共享版本号、源码提交和构建矩阵。

## 范围

- 新增协助战斗关闭／保护／全部，默认保护约定的村民、铁傀儡及已驯服生物。
- 技能成长、阿兹特克增距与诅咒、关刀前三段浮空及缩距。
- 指定饰品攻击／生命百分比与最大生命相关治疗。
- 当前值简版、按住 Alt 展开公式、GUI 更新、完整本地化和长饰品提示换行。
- 保持现有世界兼容；更新后重启客户端与服务器，无需新世界或新区块。

不将其他玩家英灵保护、通用装备栏、新英灵或 26.3 支持等社区候选加入本次范围。关刀浮空与阿兹特克距离的后续调参仍由作者决定，不声称已完成所有战斗手感或第三方模组组合的验收。

三平台共用 `CHANGELOG.md` 的 0.3.0 英文正文。玩法和百科、源文及其他语言已在前序任务同步，本轮版本号及发行记录变更不产生新的百科语义。
