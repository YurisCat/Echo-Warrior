## 中间问题与处理

实机发现动作栏及原版 Fabric 遗物长说明超宽，按作者选择局部换行。
中间的 1.21.1 绘字描述符返回类型错误被生产客户端启动检查拦住；修正为 int 并加入打包守卫。
物品栏绕过 ItemStack 便捷入口，改为集中列表入口后先用真实容器截图验证，再构建并复验正式六包。
可复用原因与守卫记录在 PORT-042；字体算法检查不替代真实界面入口验证。
缺命令权限、停止队列目录遗漏和自然史莱姆干扰属于测试夹具问题，保留失败记录后修正或建立新副本，未重写旧结果。
