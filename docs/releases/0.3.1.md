## 受测包与正式 CI 原包的关系

- 狐狸节点回归使用本地准备提交 `ced7bf4d2a200b1dd1517d62405f5f0279298b43` 的 Windows 构建；该批哈希仍保留在该提交的本记录及 `build/release-0.3.1/packages/release-manifest.json`。原测试证据与候选包没有被覆盖。

- Linux CI 与 Windows 包的 SHA-256 不同，已逐条比较全部归档项：文本换行符、等价 JSON 格式，以及 1.20.1 Forge 的一个编译器生成调试变量名不同。该类仅 `patt1722$temp`／`patt1697$temp` 的字符位置编号变化；除该名称外的 class 字节相同，`javap -p -c -s` 的全部指令／签名也完全相同。所有其他 class、美术、音频和运行时数据保持一致，详见 `ci-candidate-equivalence.json`。没有把二进制哈希不同写成“受测原包逐字节相同”。
- 正式发布 CI 与无上传 CI 的八包则完全逐字节相同；CF CDN、GitHub 附件和 MR 主文件均对应上表正式哈希。

正式本地副本为 `build/release-0.3.1/published-packages/`，汇总包为 `build/release-0.3.1/echo-warrior-0.3.1-published-eight-packages.zip`，包含八包、CL、校验和与平台清单。此前的 `packages/` 和不带 `published` 的 ZIP 保留为本地验收候选。
