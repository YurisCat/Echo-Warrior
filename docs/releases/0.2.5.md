# Echo Warrior 0.2.5 发布记录

## 范围与授权

2026-10-10，作者明确授权整理 CL、推送 GitHub，并发布 CurseForge 和 Modrinth。0.2.5 修复 Minecraft 1.20.1 Forge 联装 Apothic Attributes 时，英灵属性初始化早于第三方 owner 绑定导致的召唤器预览/创建崩溃。可选兼容入口保留无 Apothic 的原行为，不改成长公式、存档、网络或玩法。1.21.1 与 26.1.2 只同步版本号，仍按既有流程从同一提交生成六包。

公开 CL 以 `CHANGELOG.md` 的 0.2.5 章节为准，GitHub、CurseForge、Modrinth 使用同一英文内容。没有玩家文案或游戏规则变化，故无需更改本地化或百科。MC 百科工具、投稿资料及配音稿不包含在此次提交内。

## 已完成的修复回归

- 原报告组合：Minecraft 1.20.1 / Forge 47.4.20 / Echo Warrior 0.2.4 / Apothic Attributes 1.3.7 / Placebo 8.6.3。官方 CurseForge 导入分享包后，启用分享时被禁用的 Apothic，使用正式 0.2.4 原包自然复现 `An AttributeMap object was modified without a set owner!`。
- 条件选择插件使用后续 Mob 构造边界，避免依赖两个 LivingEntity 尾部注入的排序。与失败实例相比，73 份配置/数据和 38 个第三方 JAR 一致，只替换本体后五英雄真实预览、召唤、AI 命中和撤回通过。
- FOXY 任务 `20261010T034819Z-79120`：无依赖 Fabric/Forge 各两次专服启动，加 Apothic + Placebo + TBF 0.2.3 的 Forge 两次启动，共六次启动/磁盘重载通过。六份日志均通过五英雄高属性检查，联装两次均通过 TBF 100 次实际处理器循环。
- 回收箱的 144 顶点失败另行确认是自测把 72 模型顶点与 ShadowDrop 的 72 阴影顶点合计的误报。改为按材质通道计数，模型仍严格要求 72；同包有/无 ShadowDrop 对照、实际 27 格菜单、三颗钻石存取守恒和箱盖开合通过，实机截图已检查。该整合包其他模组仍有资源/配方/进度错误，不宣称整包零错误。
- 普通 Fabric 正式客户端 `apothic-pack-recycler-clean-fabric-20261010T041157Z` 全套检查和严格日志门禁通过，正常保存退出，所有进程清理完成。
- 最终预发行源码双加载器构建、产物检查、52 项资源等价/损坏包守卫、9 项客户端准备器及 13 项联装输入检查通过。修复后的最后一次变动仅为客户端自测，服务端 class 与六启动回归版本逐字节一致。
- 测试工具同时保留本轮使用的 Windows 控制台宿主清理保护和正式依赖/配置哈希记录，不影响游戏运行逻辑。
