# Echo Warrior 0.2.8 发布记录

## 范围与授权

2026-10-14，作者明确授权以 0.2.8 整理 CL、推送 GitHub，并发布 CurseForge 和 Modrinth。

修复遗迹自然生成、异地补位与管理员生成中的同步区块等待，改为有预算的分阶段准备、就绪后检查与放置、失败退避和临时 ticket 清理。补齐 1.20.1/1.21.1 自然生成入口遗漏的 512 格间距检查；既有遗迹和旧格式补位任务保留。生成可能更慢，但不再在这条路径等待区块完成。没有改动英雄、战利品数量或语言文案。

三平台共用 `CHANGELOG.md` 的 0.2.8 英文 CL。六包为 26.1.2 Fabric/NeoForge、1.21.1 Fabric/NeoForge、1.20.1 Fabric/Forge。内存持续增长仍是独立待查反馈，不将本次修复描述为消除全部内存泄漏或 GC 压力。

- 全部 42 个原活动遗迹中心保留；原三条补位任务完成一条，另两条保留原点和种子继续退避。新增遗迹均通过与其他活动中心的 512 格距离核对。
