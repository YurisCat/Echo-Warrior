# 0.2.3 性能修复发布记录

2026-10-05 作者明确授权由 Codex 评估最后一轮冒烟需要，并发布 GitHub、CurseForge 与 Modrinth，附更新日志。采用 Release，26.1.2 Fabric/NeoForge、1.21.1 Fabric/NeoForge、1.20.1 Fabric/Forge 六包同步。依赖版本不变。

## 改动与验收范围

- 修复 1.21.1/1.20.1 罗盘锁定/范围搜索遍历全世界区域，以及每秒集中轮询全部考古登记位置造成的服务器开销。
- 锁定目标直接查询区域索引；2048 格附近查询最多 49 个区域。考古状态由真实方块移除回调更新，区块重载只核对当前区块。
- 保留负坐标、跨区域边界、保底完成与剩余清场的正确行为；兼容已有世界，无需新世界/新区块。换包后重启客户端及服务端。
- 26.1.2 运行逻辑未改，仅同步版本号；不改玩法、定位距离、声音、冷却、玩家文案或翻译。无百科/语言内容变更。
- 更新日志源为 `CHANGELOG.md` 0.2.3 章节，三个平台沿用同一内容，不声明未经原整合包 Spark 实测的改善百分比。

四加载器修复候选已在狐狐副机 FOXY-NODE 完成六次真实发行专服启动、性能自测与 1.20.1 磁盘重启回归，见 [首轮副机证据](../FOXY_TEST_2026-10-05.md)。此次没有改客户端表现，沿用既有客户端/人工验收；发布前对正式构建产物补专服冒烟并完整检查六包。原反馈者未提供 Spark 和日志，原整合包改善幅度、实际多人视觉/听感仍需其复测。

本地化发布门禁：0 硬错误、0 待处理；未使用翻译豁免。保留工作区其他尚未提交的资料整理和开发客户端配置变更，不将其混入性能发布。
