# 0.2.2 Release 记录

## 授权与范围

2026-09-20 作者在逐项修复复测后反馈没有发现剩余问题，明确指示发布。采用 Release，三个 Minecraft 版本六包同步；1.20.1 为 Fabric / Forge，1.21.1 与 26.1.2 为 Fabric / NeoForge。不是 1.20.x 或 1.21.x 全系列声明。

玩家更新说明见 CHANGELOG.md 的 0.2.2 章节；每个 CF 文件都使用该章节，并声明正确依赖。不修改原有玩家译文；全部目标语言登记接受基线的依据见 `../localization/GPT6_INDEPENDENT_REVIEW.md` 末尾。

本记录首先随发布候选存档。GitHub/CF 上传是否完成应查看后续发布结果记录及 Actions 的实际文件 ID，不能从“候选已通过”推断已公开。

## 验收边界

- 作者的最终反馈是总体抽查接受，不替代逐项、所有加载器、真实双人和第三方组合的完整签收。
- 1.20.1 实际专服验证各 1～8 层雪下的遗迹放置；其他两条线由共享逻辑一致性守卫及构建覆盖，没有本轮逐层雪地实机验收。
- 跨版本迁移世界不在支持范围；升级前备份，不将高版本存档降级打开。
- 本轮发布工具和基线登记不改变玩法，因此无需额外修改百科；此前积雪规则已同步百科。
