## 使用说明

- 1.20.1 对应 **Forge**，不是 NeoForge。两种加载器分别测试，不能把两个模组包同时安装。
- Java 17；Fabric 需要 Fabric API；两端都需要对应加载器的 SmartBrainLib 1.15、GeckoLib 4.8.4。
- 桌面“Echo Warrior 1.20.1 Forge 测试端（进世界自动暂停）”会编译当前源代码，进入 CATTEST 并保持暂停。返回游戏后恢复鼠标控制。
- 对外部测试员交付 `fabric/build/libs` 或 `forge/build/libs` 中的普通 JAR；不要交付 `sources`、`common`、`devlibs`。
- 不降级高版本存档。现有 1.20.1 存档先备份；自然遗迹分布使用新世界或新区块。记录加载器、JAR SHA-256、游戏模式和复现步骤，附 `latest.log`。
- 同一时间只开一个测试客户端。下列条目可统一测一轮；只修局部问题时优先复测受影响条目及关联边界，不要求每次完整重测。
