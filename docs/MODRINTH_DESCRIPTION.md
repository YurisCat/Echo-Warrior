Unearth ancient relics and summon animated warrior companions with unique skills, talents, and customizable loadouts.

## English description

### Archaeology meets warrior companions

Follow the Echo Compass to ancient battlefield dig sites, brush suspicious ground, and recover Echo Relics. Install a relic in the portable Echo Summoner to call a warrior from the past to explore and fight at your side.

Each battlefield contains one guaranteed relic. Archaeology can also uncover accessories, Legacies, supplies, and collectible Knowledge Fragments.

### Five distinct warriors

- **Roman Legionary:** a shield-bearing defender with protective skills.
- **Aztec Warrior:** a heavy melee hunter with sweeping attacks and bleeding.
- **Egyptian Archer:** a mobile ranged fighter with selectable arrow types and volleys.
- **Chinese Guandao Warrior:** an armored area fighter with growing combat power and a four-hit combo.
- **Japanese Samurai:** a mobile duelist with dodges, dashes, and afterimages.

Echoes gain experience from kills they help secure and can reach level 30. Relic talents and 25 accessories let you customize their abilities.

### Getting started

1. Craft an Echo Compass and take a brush to a battlefield dig site.
2. Recover an Echo Relic and install it in an Echo Summoner.
3. Add Rotten Flesh, Soul Sand, or Soul Soil as fuel, then summon your Echo.
4. Configure skills, Follow/Wander/Wait activity, and Aggressive/Defensive/Peaceful behavior in the summoner interface.

Craft **Echoes, Warriors, and You** with a Knowledge Fragment and a book for an in-game guide. Combine Knowledge Fragments into a collection, and use the Echo Salvage Chest to recycle unwanted finds.

### Installation

Choose the file for your exact Minecraft version and loader:

| Minecraft | Loaders | Java |
| --- | --- | --- |
| 26.1.2 | Fabric / NeoForge | 25 |
| 1.21.1 | Fabric / NeoForge | 21 |
| 1.20.1 | Fabric / Forge | 17 |

Install **GeckoLib** and **SmartBrainLib** for the same Minecraft version and loader. Fabric also requires **Fabric API**. These dependencies remain separate from the mod.

For multiplayer, install matching Echo Warrior and dependency versions on both the client and server. Back up worlds before updating, and do not open a newer Minecraft save in an older game version.

## 中文正文

### 考古与英灵伙伴

跟随回声罗盘寻找古战场遗迹，用刷子发掘可疑地表中的英灵遗物。把遗物装入便携的回声召唤器，就能召回过去的战士，与你并肩探索和战斗。

每处战场都有一件保底遗物，也可能挖出饰品、传承、补给和可收集的知识碎片。

### 五位各有特色的战士

- **罗马军团兵**：手持盾牌、擅长防护的前排战士。
- **阿兹特克勇士**：使用沉重横扫与流血攻击的近战猎手。
- **埃及弓箭手**：能够切换箭型、齐射并灵活走位的远程战士。
- **中国关刀战士**：以重甲、范围攻击和四段连招见长，战斗中不断强化。
- **日本武士**：围绕闪避、突进与残影展开的高机动决斗者。

英灵从参与击杀中获得经验，最高成长至 30 级；遗物天赋和 25 件饰品提供不同的搭配选择。

### 开始游玩

1. 制作回声罗盘，带上刷子寻找战场遗迹。
2. 发掘英灵遗物，把它装入回声召唤器。
3. 投入腐肉、灵魂沙或灵魂土作为燃料，然后召唤英灵。
4. 在召唤器中设置技能、跟随／闲逛／等待活动模式，以及主动／被动／和平警戒模式。

用知识碎片和书合成教程手册《回声、战士与你》，查看游戏内指引。知识碎片可以合并收集，重复的发现可交给英灵杂物回收箱处理。

### 安装

选择与 Minecraft 版本和加载器完全匹配的文件：26.1.2 支持 Fabric／NeoForge，使用 Java 25；1.21.1 支持 Fabric／NeoForge，使用 Java 21；1.20.1 支持 Fabric／Forge，使用 Java 17。

所有包均需安装同版本、同加载器的 GeckoLib 和 SmartBrainLib；Fabric 还需 Fabric API。前置独立安装。多人游戏的客户端和服务端都应安装匹配的模组及前置。更新前备份世界，不要用旧版 Minecraft 打开新版存档。
