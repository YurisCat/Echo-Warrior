Echo Warrior 测试用例

适用版本 0.1.0-test.20260901.1。这是可离线使用的单文件测试工具：逐项执行、记录实际结果、附加截图，最后导出独立结果 HTML 或可继续编辑的 JSON。

P0 先测崩溃、存档、物品丢失、复制、核心流程与多人控制权。
按步骤复现不要只写“坏了”；记录位置、模式、物品、人数和稳定复现步骤。
保留证据失败时附截图；崩溃或异常同步同时保留 latest.log。
