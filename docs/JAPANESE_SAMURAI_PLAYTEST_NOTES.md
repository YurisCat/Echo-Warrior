# 日本武士粗初版：模型师测试 CL

更新时间：2026-08-26

这是一版用于动作、刀身、命中时点和残影观感验证的粗初版，不代表最终动画节奏或特效质量。测试时优先记录“动作画面与代码判定是否对齐”，不需要因为临时粒子粗糙而返工模型。

## 本次可测试内容

- 日本武士已经能通过召唤器和遗物正常召唤，模型、贴图、刀身、待机、行走、受伤和主要战斗动作均已接入。
- `残心`：生命越低闪避率越高；实际完成一次伤害段后短暂增加闪避率。成功闪避会恢复一层踏込。
- `踏込`：目标在普通攻击范围外、8 格以内且路径安全时，自动播放 `dash_forward` 向目标冲刺。当前冲刺后半段尚未绑定攻击伤害，等新版动作确认后再处理。
- `斩`：普通攻击会在第一刀命中后判断是否还有正面目标；有目标则接第二刀，无目标则收刀。
- `刺`：自动播放刺入和拔刀，当前伤害时点暂定为动作起手后第 16 与 20 tick。
- 闪避残影已经有基础快照版和可选溶解版。溶解版同时具备按年龄递减的真实透明度，越早生成的残影越早变淡；踏込与后撤残影只会留在本体已经经过的位置。描边 2B 暂时禁用，因为现有实现会变成白色实心剪影。

## 运行时动画映射

| 模型/导出动画 | 当前用途 | 需要观察 |
| --- | --- | --- |
| `idle` | 待机与呼吸 | 刀是否一直稳定握在手中，回待机时是否跳帧 |
| `walk` | 普通移动与追敌 | 手腕、刀柄和刀身是否同步，脚底是否明显滑步 |
| `hurt` | 非完整动作中的受伤 | 结束后能否自然回到待机；不得覆盖攻击、踏込或刺 |
| `attack_first` | 第一刀起手到第一刀结算 | 刀锋穿过目标的时间是否接近第 13 tick |
| `attack_recover` | 第一刀后无目标时的收势 | 与 `attack_first` 末帧、`idle` 首帧是否连续 |
| `attack_follow` | 第一刀后继续第二刀 | 第二刀刀锋穿过目标的时间是否接近该段第 13 tick |
| `stab` | 刺入与拔刀 | 刺入、拔刀视觉时点是否分别接近第 16、20 tick |
| `dash_forward` | 踏込向前冲刺 | 起步爆发、停止姿态、刀身稳定性；末段攻击暂不判定 |
| `dash_backward` | 空闲/行走/追敌状态下的真实闪避 | 后撤方向是否自然，结束时是否突然旋转或跳回待机 |
| `attack_1` / `attack_2` | 保留的原始整段动作 | 运行时不直接播放，由拆分后的三个片段负责分支 |
| `attack_3` | 暂不使用 | 本轮无需测试 |

## 普通攻击位移与判定

- 第一刀从起手到命中帧最多以 `0.30 格/tick` 追随锁定目标，累计最多 `1.5 格`，距离约 `1.7 格`时停止靠近。
- 第二刀只追随第一刀分支时记录的主目标，最多 `0.20 格/tick`，累计最多 `0.75 格`。
- 每段每 tick 最多转向 `15°`，相对该段起始朝向最多转 `±45°`。
- 追随只能走安全路径和一格台阶；遇墙、失去视线、危险落差或目标转出角度时停止位移，但攻击动画继续。
- 这段小位移不是踏込：没有无敌、充能消耗或残影，只有少量脚下扬尘。
- 第一刀只有极轻击退，目的是避免把目标推出第二刀范围；第二刀保留明显的终结击退。

## 残影测试指令

以下指令作用于玩家 32 格内最近的所属日本武士：

```mcfunction
/echo_warrior visual samurai_afterimage_advanced off
/echo_warrior visual samurai_afterimage_advanced on
/echo_warrior visual samurai_afterimage_neutral on
/echo_warrior visual samurai_afterimage_neutral off
```

- 新召唤的武士默认已经开启 2A，并使用无额外附色的原始贴图溶解。
- `advanced off/on`：关闭或重新开启约 2 tick 完整保持、随后逐步溶解的 2A 效果。
- `neutral off`：主动开启高对比灰度细节乘以高饱和残心青/踏込金。
- `neutral on`：关闭额外附色，恢复默认的完整原贴图颜色。
- 2A 主体按场景光照显示，不再强制全亮；会覆盖贴图的白色整模型边缘通道已经移除。
- `/echo_warrior visual samurai_afterimage_outline on` 当前应明确拒绝开启；这是预期行为，不是新的故障。

## 请模型师重点反馈

1. 刀身在待机、移动、两刀、刺、前冲、后撤和受伤动作中是否始终存在，是否有翻面消失、穿手或脱离刀柄。
2. 第一刀第 13 tick、第二刀片段第 13 tick，以及刺的第 16/20 tick，是否分别对应刀锋真正穿过目标的位置。
3. `attack_first → attack_recover → idle` 与 `attack_first → attack_follow → idle` 两条路径是否有姿势突跳、手腕翻转或刀身瞬移。
4. `dash_forward` 到达目标附近时，后半段攻击姿势应如何拆分；请标出希望绑定伤害的准确关键帧。
5. `dash_backward` 结束后是否自然回到待机/移动，是否需要单独的结束过渡片段。
6. 高饱和青色、金色和原色三种残影下，甲片、布料与刀身是否都能辨认；若仍过亮，请附白天和夜间各一张截图。
7. 连续触发踏込时，确认任何一帧都没有残影越过武士本体；队列最前端的旧残影应比后生成残影更早变透明、消失。

## 已知的粗初版限制

- 踏込后半段攻击尚未定义伤害与命中时点。
- 刺的两个命中时点仍是暂定值，等待模型师校准。
- 溶解 2A 默认开启、额外青色/金色附色默认关闭；真正的整体外轮廓 2B 尚未实现。
- 脚下扬尘、血液和短刀光仍是程序员占位效果，后续会按实机画面继续调整。
