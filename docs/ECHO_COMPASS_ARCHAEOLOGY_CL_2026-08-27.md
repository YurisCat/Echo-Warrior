# 回声罗盘与战场考古 CL（2026-08-27）

本次版本完成了非武士内容中的第一版“回声罗盘 → 寻找战场遗迹 → 刷出遗物 → 遗迹延迟补充”闭环，并加入了供后续内容使用的占位考古奖励与首批可实际生效的英灵模块。

## 回声罗盘

- 回声罗盘不增加额外界面；遗迹外使用原版 32 帧指针，指向 2048 格内持久化索引中最近的未完成遗迹中心。
- 进入遗迹内或附近没有可响应目标时，指针会稳定、持续地顺时针旋转，不再使用原版随机左右摆动；遗迹内仍由方向、音量和频率共同引导考古目标。
- 普通右键只切换当前这个罗盘的“遗迹外远途提醒音”，不会关闭指针或遗迹内回响，也不会自动改变其他罗盘的开关。
- 多个允许提醒音的罗盘同时存在时，每名玩家仍只播放一个。优先级为主手、副手、快捷栏从左到右、主背包从左到右；所有罗盘指针都会工作。
- 罗盘仅在主世界工作，也不会扫描方块、强制加载区块或主动触发世界生成。
- 进入未完成战场遗迹 320 格范围后，罗盘开始播放只有持有者能听见、位于玩家自身的轻微远途提醒；越近间隔由约 12 秒缩短到约 4 秒。
- 进入遗迹中心 24 格内切换为遗迹内模式，离开 48 格后才恢复外部指针，避免边界抖动。指针随关键方块距离由约 1.6 秒一圈逐渐加快到约 0.4 秒一圈；遗迹内回响具有空间方向，越接近目标越响、间隔越短。无可响应目标时保持约 0.5 秒一圈的快速顺时针旋转。
- 罗盘每约 2 秒只查询一次遗迹索引，不扫描方块、强制加载区块或主动触发世界生成。2048 格内没有目标时会提示一次“附近没有可响应的战场回声”。
- 保底方块被刷出或以其他方式移除时，该遗迹立即完成。完成瞬间已经跟踪该遗迹的玩家进入个人清场模式：回响稳定锁定一处剩余考古方块，目标消失后再选择最近的下一处，并显示“仍有 N 处回声等待被揭示”。
- 全部登记方块消失后立即提示“此处的回声已经平息”并寻找新遗迹；仅完成保底后离开遗迹中心 48 格持续 3 秒，也会结束清场。符合范围和携带条件时，清场归属可跨登出与服务器重启恢复。
- 配方为中心指南针、上下左右四个紫水晶碎片、四角四个铜锭。
- 熟练工等级制图师必定提供回声罗盘交易：4 个绿宝石加 1 个指南针，最多交易 2 次。

## 战场遗迹与重复生成

- 战场遗迹表现为直径约 15–21 格的不规则小空地，地表会适应沙地、砾石、草地或泥土地形。
- 生成会检查自然、平坦与安全条件，只清理可替换植被，不主动砍树，也不会覆盖明显被玩家建设过的区块。
- 每处遗迹包含 6–9 个可疑方块，其中恰好一个是保底遗物方块；沙与砾石使用原版考古方块，草与泥土使用本模组的稳定可疑方块。自定义方块从未刷状态起带有近看可辨认的低对比度断裂回声纹，四个刷取阶段会逐步显露更多裂纹；纹理不使用亮色高光，未标记区域保持原版地表像素，同时可疑草继续服从所在地生态群系染色。
- 世界按 48×48 区块区域管理，每个区域最多保有一处活跃遗迹，相邻遗迹中心至少间隔 512 格。
- 遗迹完成后进入 24,000 游戏刻冷却。冷却结束后只会在合适区块自然加载时尝试补充，不会为计时或生成强加载区块。
- 已探索区域首次具备资格时会等待约 2–5 分钟；新加载区块通常等待约 2–30 秒。全局生成尝试做了节流，避免玩家拿着罗盘连续跑图造成密集生成。
- 区块是否被玩家改造、遗迹状态、全部 6～9 个考古坐标、共享剩余数量、玩家清场归属与补充冷却都会持久保存，供服务器重启后继续使用。
- 刷取、直接破坏、爆炸、替换或重力方块从原坐标下落都会使对应登记目标从共享计数移除，因此落到火把或尖锥后消失的可疑方块不会永久卡住罗盘。

## 战场考古奖励

普通可疑方块采用以下精确概率：

- 铁锭：40%
- 小知识占位物：30%
- 五种传承占位物合计：20%
- 金锭：8%
- 五种遗物合计：1.5%
- 下界合金碎片：0.3%
- 三种模块成品合计：0.2%

保底方块被正确刷取时，会额外保证产出五种英灵遗物之一，五种遗物等概率。若保底方块被直接破坏、替换或以其他非刷取方式移除，遗迹仍会完成，但不会补发保底遗物。

## 占位物品与英灵模块

- 新增“小知识”与勇气、坚毅、纯净、智慧、工艺五种传承占位物；当前复用原版物品模型并通过颜色区分，后续可直接替换正式素材与行为。
- 板甲模块：护甲值 +2。
- 全身锁链甲模块：护甲值 +4，移动速度 -10%。
- 尖刺护甲模块：护甲值 +2；英灵受到近战伤害后，按实际扣除生命值 1:1 反伤，反伤仍受攻击者护甲减免。
- 反伤不会由投射物、爆炸、魔法、环境伤害触发，也不会递归触发另一层反伤。
- 同名模块最多安装一个，不同模块可以叠加；模块变化会实时刷新已经绑定的英灵属性。
- 召唤器界面展示模块实际结算后的数值，提升项显示为绿色，降低项显示为红色。
- 这三种模块已加入正式配方与战场考古极小概率成品掉落；占位小知识与传承暂未实现最终阅读／使用效果。

## 请重点检查

1. 在主世界从 32～50 格外接近遗迹，确认外部指针明确指向遗迹中心；跨越 24／48 格迟滞边界时不会反复跳模。
2. 进入遗迹后绕行，确认指针始终连续顺时针旋转且越接近关键方块越快；方向回响应准确收束，距离越近越响且越频繁。2048 格内没有目标时也应快速顺时针旋转而非左右随机摆动。
3. 分别刷取和直接破坏保底方块，确认两种方式都会完成遗迹，但只有正确刷取会得到保底遗物。
4. 完成保底后确认显示共享剩余数量，回响逐个锁定剩余方块；破坏、爆炸或令可疑沙／砂砾下落消失时计数也会减少。清空或离开 48 格持续 3 秒后确认罗盘寻找新遗迹。
5. 在沙漠、草地和泥土地形检查遗迹外观、可疑方块类型、四阶段裂纹，以及未刷状态能否凭断裂回声纹与普通草／泥土区分；同时确认草色匹配生态群系、树木受保护且不会覆盖玩家建筑。
6. 在召唤器中安装三个模块，确认同名模块无法重复安装、不同模块可以叠加，且绿色／红色数值与英灵实际属性一致。
7. 使用尖刺护甲分别承受近战、箭矢、爆炸和环境伤害，确认只有近战实际生命损失会产生一次反伤。

## 验证与当前限制

- 管理员可用 `/echo_warrior battlefield generate [数量]` 在 2048 格内强制请求 1～8 处正式遗迹（默认 1），用 `/echo_warrior battlefield locate` 查询最近的未完成遗迹与保底方块坐标，并用 `/echo_warrior battlefield teleport` 传送到遗迹中心外随机 32～50 格的安全位置。生成任务会分散到后续服务器刻执行并逐处报告进度，避免同步批量生成新区块冻结服务器；它仍遵守正式区域、512 格间距与全部安全检查，可能只部分成功。
- 修复了手动放置可疑草方块／可疑泥土时，原版刷取方块实体拒绝自定义方块状态而导致的客户端崩溃。
- 修复了区域已到生成时间、但唯一候选区块已经卸载后长期不再尝试的问题；现在会在当前自然加载的区块中轮换候选，仍然不会强加载区块。
- 修复了安装模块后，绿色／红色属性数字因缺少不透明通道而完全不可见的问题。
- 可疑草方块现在使用所在地的生物群系草色，不再以固定颜色突兀地出现在遗迹中。
- 修复了自定义可疑草方块和可疑泥土完全复用普通方块模型、导致未刷与刷取各阶段肉眼均无法区分的问题；纹理由可复现的项目内生成脚本维护。
- 根据游戏内观感移除了回声纹的亮色高光与紫色色偏，并大幅降低未刷阶段对比度，避免整个方块形成发白的提示块。
- 遗迹内与无目标指针已改为确定性顺时针动画；关闭原版指针惯性后，玩家转身不会再把它表现成随机左右摆动。
- 已使用 Java 25 通过完整 `gradlew.bat build`，并验证全部新增 JSON 可解析、考古权重总和与上述概率一致。
- 当前图标全部是原版模型加染色的占位方案，回声也复用原版紫水晶声音；正式美术与定制音频可以在后续迭代中无损替换。
- 已备份旧 `CATTEST` 并按相同世界生成设置重建测试存档。实际生成验证得到 4 处活动遗迹，中心分别为 `(73,69,-4)`、`(988,69,-394)`、`(-1404,68,1174)`、`(1589,70,685)`；存档索引确认四处分别登记 8、8、9、7 个考古方块，且另有 3 个新世界自然加载区域处于等待生成状态。
- 同步批量生成 4 处时曾造成约 132 秒服务器落后，因此正式指令已改为分刻异步任务；最终代码已重新使用 Java 25 通过完整构建。指针观感、声像手感与清场交互仍需要玩家在游戏内继续手动体验。
- 世界生成测试需要进入新世界或自然加载符合条件的新区块；数据／资源类后续调整可优先使用重载流程。
