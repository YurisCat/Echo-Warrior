# 英灵召唤器测试清单

推荐使用同目录的 `SUMMONER_TEST_CHECKLIST.html`：它可以直接点击勾选、自动保存在浏览器本地，并导入/导出 JSON 测试结果。本文件用于版本库审阅和故障记录。

## GUI 与物品交互

- [ ] 召唤器在物品栏、快捷栏、创造模式“英灵回声”标签页、手持与掉落状态下均使用同一张静止灰色单帧图标，不再播放旧序列帧。
- [ ] 分别装入五种英灵遗物：GUI 图标在按住 Shift 时切换为对应遗物，松开后立即恢复；空召唤器按住 Shift 仍保持灰色图标。
- [ ] 手持召唤器普通右键打开 GUI；没有装入遗物时仍能正常打开。
- [ ] 打开 GUI 后世界背景像原版物品栏一样变暗，GUI 与槽位坐标不偏移。
- [ ] 除召唤器所在槽位外，玩家物品栏、快捷栏、拖动、Shift 移动均正常。
- [ ] 召唤器所在槽位无法拿走、Shift 移动、数字键交换或丢弃；空鼠标左键该槽也不能拿起召唤器。
- [ ] 遗物装入后名称、模型、八项属性、技能和天赋立即出现；取出后立即清空并遣散英灵。
- [ ] 0～4 个天赋按固定顺序从右向左显示，图标与名称/效果对应正确。
- [ ] 技能、天赋、行动模式、警戒状态、经验条、燃料条均有正确悬浮说明。
- [ ] 空燃料输入槽显示燃料说明；槽中有物品时只显示该物品的原版悬浮框。
- [ ] 空饰品槽悬浮时依次显示“饰品槽”“在此安装英灵饰品”“同名饰品不能重复安装”；放入饰品后只显示该物品的原版悬浮框，取出后空槽说明恢复。
- [ ] GUI 中不再出现“布局”按钮、布局拖拽框或保存/撤销/重置入口，正常槽位与按钮交互不受影响。
- [ ] 鼠标拿起燃料、遗物或兼容饰品后左键玩家物品栏中的召唤器，会分别放入燃料槽、空遗物槽或首个兼容空模块槽；召唤器 GUI 开启时，左键其中被锁定的召唤器物品槽也能完成同样的快速投放。冲突/无效物品不变化，普通物品不能进入模块槽，旧存量模块仍可取出。
- [ ] 腐肉、灵魂沙、灵魂土成功左键装入时，各播放一轮从召唤器格中心随机外爆到格外、再聚回中心的粒子；腐肉为棕红色，灵魂沙/土为青蓝色，每次方向与距离不同。冲突燃料、满槽、无效物品和失败装入不播放。
- [ ] 遗物或兼容饰品成功左键装入召唤器时，物品格上立即出现一道较宽、较慢并带过冲缓动的白色斜光条，从上方向右下角扫过并淡出；白光逐像素贴合召唤器图标，只照亮非全透明像素，图标外的透明背景始终不闪。槽位冲突、饰品不兼容或其他失败装入不播放。
- [ ] 创造模式把单个活跃召唤器拖到右侧销毁槽后，对应英灵在很短的同步延迟后消失；Shift 点击销毁槽清空整栏时，所有被清除的活跃召唤器（包括原版收纳袋／容器中的嵌套实例）都正确遣散，普通换槽、创造复制和其他玩家仍持有的可见副本不会被误遣散。
- [ ] 所有数值使用真实服务端状态，生命/攻击/护甲的小数显示正确。

## 遗物、天赋与成长

- [ ] 创造栏展示的遗物保持未鉴定；真正取入玩家物品栏后才随机初始化一次；`/give` 遗物同样在进入物品栏后初始化。
- [ ] 遗物可能生成 0～4 个天赋，2 个最常见；同一天赋不重复。
- [ ] 已鉴定遗物未按 Shift 时只显示等级、经验、天赋名称和“按 Shift 查看更多”；按住 Shift 后才在各天赋名称下展开说明。中文与 English (US) 均无缺失、溢出或翻译键原样显示。
- [ ] 坏脾气/慵懒互斥，瘦削/壮硕互斥；“平凡”不生成。
- [ ] 复制遗物保留天赋、等级、经验、技能开关和模式，不会重新随机。
- [ ] `/echo_warrior relic reroll_traits` 只作为开发命令工作。
- [ ] 英灵或主人共同参与击杀会增加遗物经验，不减少玩家经验球。
- [ ] 升级需求为 `15 + 2 × 当前等级`，30 级封顶；满级生命 60、攻击 12（无天赋时）。
- [ ] 升级立即刷新在场英灵属性并播放行动栏提示和玩家升级提示音。

## 燃料与召唤

- [ ] 新召唤器燃料为 0/1000；腐肉 +20，灵魂沙和灵魂土均 +50。
- [ ] 召唤器只要位于玩家物品栏且 GUI 未打开，每 5 tick 最多转化一个燃料物品。
- [ ] 同一召唤器转化燃料时，主手和副手都不会每 5 tick 下沉抽动；真正切换物品或切换到另一只召唤器时仍播放换手动画。
- [ ] 容量不足以容纳完整燃料价值时不消耗物品。
- [ ] GUI 内转化时出现 3～6 个轻微粒子，从输入槽弧线飞向燃料条。
- [ ] 燃料条宽度、粒子遮罩和悬浮数据随真实燃料同步。
- [ ] 召唤基础消耗 100，并正确受坏脾气/慵懒的消耗比例影响；创造模式同样扣除。
- [ ] 前方不安全时会在半径 4 格寻找安全位置；完全无安全位置时不扣燃料。
- [ ] GUI 召唤/收回后保持开启；收回单击立即执行，不再出现二次确认。
- [ ] 服务端确认召唤成功后，青蓝灵魂粒子从矩形按钮内部带过冲、交错延迟和随机摆动爆向按钮四周；收回成功后，蓝色粒子从四周短促反向蓄力，再加速聚入按钮内部的不同位置。两者均有自然淡出和尺寸脉冲，不集中到同一个中心点，也不扩展到全屏。
- [ ] 潜行右键在英灵未在场时执行召唤，在场时执行召回；召回不扣燃料，英灵不会因时间自然消失。
- [ ] 英灵脱战 5 秒后每 2 秒恢复 1 点生命，并按实际恢复量扣除燃料；无燃料只停止恢复。

## 模式与战斗边界

- [ ] 跟随模式正常跟随并在过远时安全传送。
- [ ] 等待模式重设当前位置锚点，平时限于 2 格；被推离或战斗结束后能够完整寻路返回，不会只迈一步便停止。主动扫描 6 格，战斗目标离开锚点 8 格后放弃。
- [ ] 闲逛模式重设当前位置锚点，通常停留 2～5 秒后连续走完约 4～8 格的有效路径；不会只迈一步便停止，也不会持续无间隔踱步。
- [ ] 闲逛会选择安全可达的陆地目标，在坡地、台阶和存在障碍的环境中能够失败重试；接近 12～14 格边缘时向锚点偏移，越过 16 格后归位，战斗追击最多 24 格。
- [ ] 闲逛可被战斗、主动技能、玩家互动和浮水正常打断；临时行为结束后短暂停留再继续，旧路径不会覆盖高优先级行为。
- [ ] 三种英灵在跟随、闲逛、归位和游泳时主要看向前进方向，不会持续侧头或回头盯着主人；普通行走侧视约限于头部 15°、瞳孔额外 10°。
- [ ] 行走中的战斗目标、苦力怕、伤害来源和快速接近目标仍能覆盖前进视线；停止移动后约 0.3 秒内自然恢复普通观察与玩家对视。
- [ ] 重复点击当前等待/闲逛模式会重新设置锚点。
- [ ] 主动出击会主动攻击敌对生物并协助主人攻击目标。
- [ ] 被动防御只响应主人/自身受击或主人攻击目标。
- [ ] 和平模式只在自身被直接攻击后短暂自卫，不因主人战斗扩大交战。
- [ ] 普通挥刀只在伤害判定帧仍处于各英灵规定的近战范围且有视线时命中；阿兹特克主目标为 2.25 格基础水平距离加目标半宽，并要求垂直碰撞箱重叠；起手后继续拉开距离或隔墙不会隔空受伤。
- [ ] 友军、同主人英灵、主人驯服生物、同队实体和创造/旁观玩家不会被攻击。
- [ ] 三种英灵落入普通河流或深水后都会主动浮向水面，持续完全潜水也不会受到溺水伤害。
- [ ] 跟随模式下把英灵困在水下屋顶或封闭水坑中；约 2 秒后其停止水下战斗并尝试游向主人，持续约 5 秒无有效位移后安全传送到主人附近的干燥地面或水面。
- [ ] 等待与闲逛模式不会因为水域逻辑被强制传回主人；阿兹特克追猎、罗马举盾冲锋和军团永存不会被水下脱困传送中途打断。

## 常驻绑定、控制权与跨维度

- [ ] 召唤后等待至少一个旧持续时间周期，英灵不会自然消散；控制者退出游戏、死亡或切换旁观后也不会被遣散。
- [ ] 控制者不可用时，跟随英灵停在当前位置并可自卫，主人定向举盾冲锋、主人光环和主人祝福停止；等待/闲逛与英灵自身技能继续运行。
- [ ] 跟随状态的五种英灵逐一通过下界传送门和末地传送迁移：新维度只出现一个实体，保留生命、吸收、燃烧/冰冻/空气及已经获得的有限自强化；旧维度实体、埃及箭矢和反射/弹开投射物不会继续结算。
- [ ] 等待和闲逛英灵不会随控制者跨维度；原区块加载时继续原活动，卸载时不强制加载，控制者返回后位置与锚点不跳到主人身边。
- [ ] 把召唤器丢在地上、放入普通箱子/潜影盒/收纳袋并退出重进，绑定保持；让掉落物自然消失、落入虚空、被火/岩浆/爆炸销毁，或销毁装有召唤器的原版嵌套容器物品时，对应英灵终止。
- [ ] 召唤器在箱子或未加载容器中时，让英灵完成击杀与参与击杀：遗物经验实时增加；随后取出召唤器，镜像正确同步且不回滚燃料、饰品、技能或经验。
- [ ] 第三者可以更换燃料、饰品、遗物、警戒状态和全部技能开关；这些操作不改变控制者。取出/替换遗物会立即遣散。
- [ ] 先召唤遗物 A 的英灵，再用鼠标直接把遗物 B 替换进同一召唤器：旧英灵在新状态提交前立即消失，召唤器 UUID 始终不变；随后点击召唤只生成 B 对应的一个新英灵，日志中不出现连续的重复 UUID 重分配警告。
- [ ] 第三者把活跃英灵切换为跟随后，控制权转交并在新控制者附近安全重建；旧动作取消且不会留下无重力、临时护甲、碰撞高度、钉身或幽灵伤害。警戒和技能按钮不转移控制权。
- [ ] 手动遣散、英灵死亡和遗物移除后重新召唤均正常扣燃料并满血生成；遗物上的技能充能和冷却按世界时间继续，不因死亡/遣散重置，关闭服务器期间不推进。
- [ ] 同一召唤器 UUID 的复制品同时进入可见库存时，先登记原件保留活跃绑定；后出现副本保留内部物品但获得新 UUID，不能控制或复制原英灵。
- [ ] 默认配置可召唤超过 8 名；第 9 名成功召唤时只提示一次性能风险，一小时内继续召唤不重复提示。设置 `maxLivingEchoesPerController` 后，超限召唤与跟随接管被服务端拒绝。
- [ ] 两个玩家同时打开同一绑定的不同镜像或快速交替操作时，过期菜单显示状态已变化并重新同步，不覆盖另一方刚完成的燃料、遗物、模式或技能修改。
- [ ] 管理员命令 `/echo_warrior binding list`、`status <uuid>`、`dismiss <uuid>` 与 `repair <uuid>` 可诊断、终止及重建在线控制者的活跃跟随绑定；repair 不会移动等待/闲逛英灵。

## 罗马条件二连击

- [ ] 基础攻速下首击约在起手第 6 tick 只结算一次；第 11 tick 才决定追击或收势，完整追击的第二次伤害约在第 16 tick 结算。
- [ ] 首击正好击杀原目标时只造成一次伤害，并从共同分叉姿势自然接入 `attack_recover`；不空挥第二刀、不残留持刀姿势。
- [ ] 高生命目标保持合法、可见且在 2.75 格追击确认范围内时，无缝播放 `attack_first` → `attack_follow`；第二击以 3.10 格判定范围只打同一 UUID，伤害为首击基础伤害的 75%。
- [ ] 首击仍受护甲和格挡影响，但不产生原版近战击退；普通目标不会因为第一击被推出范围而错误进入收势，第二击仍可产生正常击退。
- [ ] 首击后原目标死亡、被移除、变为友军、离开 2.75 格追击确认范围或隔墙时直接收势；旁边即使存在其他敌人也不会接棒承受第二击。
- [ ] 已进入追击后，目标在第二命中帧前离开范围或失去视线时只挥空，不产生隔空或穿墙伤害。
- [ ] Skinny、Perfectionist 等攻速变化会等比缩放两段动作和命中时机；高速状态下第二击不会被首击或其他来源造成的普通受伤冷却吞掉，但仍受护甲、友军保护和真正无敌状态约束。
- [ ] 完整追击或提前收势结束后才开始本次快照攻速对应的冷却；攻击过程中临时改变生命或攻速不会让当前动作中途变速。
- [ ] 举盾冲锋、军团永存、取下遗物、手动召回或遣散在任一命中前介入时，会取消待结算伤害，不会在动画停止后出现幽灵第一击或第二击；重新装回遗物也不能绕过已开始的攻击冷却。
- [ ] 静止近身目标不会让罗马原地踏步；远程目标在前摇或第二段前摇中后退时，首段最多安全追步 1.5 格、第二段最多 0.75 格，实际前移期间腿部按动作攻速自然走路，上半身攻击、盾牌、武器和表情不被行走覆盖，停步或收势时腿部立即回到站姿且无滑行。
- [ ] 在墙体、液体、火焰/岩浆/细雪、超过一格落差和等待/闲逛/跟随活动边界前测试追步：罗马停在最后安全位置，腿部同步停止，但攻击动作继续按既定分支结算或挥空，不穿墙、不越险、不瞬移到目标身边。
- [ ] 攻击中受伤不会抢占上半身攻击动作，但疼痛闭眼、表情和伤害来源注视仍会发生；行走起攻、动作结束后继续移动及盾牌切换均无单帧旧姿势或 T-pose。
- [ ] 双客户端观察到相同的追步、追击/收势分支与命中次数；下半身只在服务端实际前移时播放行走层，追击分支没有额外的网络重触发停顿。

## 士兵阵列

- [ ] 技能启用后士兵阵列始终生效，不需要附近存在敌人；可在 GUI 技能栏手动关闭。
- [ ] 自身、主人和同主人英灵获得不叠加的 +2 攻击力。
- [ ] 未持盾时增益显示为无限持续的“举起武器！”状态效果，并使用对应的独立状态效果图标，不出现低持续时间闪烁。
- [ ] 从范围外进入 8 格立即获得；生效后短暂越过 8 格不会闪烁，只有超过 8.75 格连续 10 tick 才因距离移除。技能禁用、来源卸载/死亡/遣散、主人离线/死亡/旁观、跨维度或绑定失效会立即移除。
- [ ] 普通阵列固定提供不叠加的 +2 攻击。
- [ ] 主人在 8 格内任一只手持盾时，状态效果立即切换为“举起盾牌！”及对应图标；攻击仍只增加 2，主人和军团兵获得 15% 最终伤害减免。
- [ ] 放下或移走盾牌后，状态效果立即切回“举起武器！”，不同时残留两个效果。
- [ ] 光环生效时退出世界再重新进入，不会留下无法清除的无限状态效果；旧版本的“士兵阵列”效果也会在上线时清除。
- [ ] 同一受益者附近放置多个普通/盾阵列来源时，只保留最强盾阵列且攻击不叠加；最强来源离开后原子降级，不会一帧同时残留两个效果。
- [ ] 用命令或存档人为制造“效果已消失但永久攻击修饰器仍在”以及“效果仍在但来源已消失”两种状态；最多 10 tick 后反向审计恢复正确，不会永久加攻。
- [ ] GUI 中士兵阵列技能框保持普通白边，不因光环生效出现黄色外框；举盾冲锋充能数字比上一版向下 1 像素且仍清晰可读。

## 军团壁垒

- [ ] 从军团兵身体正前方、前方 45°、左右边界内侧分别进行普通近战攻击，实际伤害均为关闭技能时的 50%；护甲仍先正常结算。
- [ ] 从身体正后方和左右边界外侧进行同类近战攻击，伤害不减；受击前转身会立即改变判定半区，头部或瞳孔单独转动不会改变防护方向。

## 举盾冲锋

- [ ] 初始 3 点充能，每 5 秒恢复 1 点；未召唤或放在容器中也按世界时间恢复。

- [ ] 原射手仍合法时，投射物反弹瞄准原射手；原射手死亡、卸载或失效时改瞄准 16 格内最近可见敌对生物；两者都不存在时沿远离主人的方向弹飞。
- [ ] 反弹保留投射物原速度和伤害，归属改为军团兵且不会再次触发拦截；潜影弹会替换或清除追踪目标，不会转弯继续追主人。

- [ ] 撞击蓄爆苦力怕造成军团兵当前攻击力 200% 的普通伤害，仍正常经过目标的护甲、减伤与无敌帧结算。
- [ ] 苦力怕被沿“远离主人 70% + 冲锋方向 30%”击退约 5～7 格，目标立即清空，随后 40 tick 内不会自然重新锁定或继续蓄爆。

- [ ] 冲锋最多约 1 秒，路径阻塞会取消，不沿途造成伤害，只产生轻微推挤。
- [ ] 图标显示 0～3 充能，恢复过程使用从 12 点方向顺时针的像素遮罩。
- [ ] 冲锋开始后播放并维持举盾动作，命中、超时或取消后才播放收盾动作。
- [ ] 举盾期间头部保持笔直并朝向正前方，不被上半身的 30° 举盾旋转带歪；瞳孔仍能小幅独立观察目标。
- [ ] 冲锋速度按“平稳起步—中段加速—末段收势”变化，不是僵硬的恒速滑行。
- [ ] 冲锋沿途有低频风弹掠过声和少量尾流，命中投射物或苦力怕时播放盾牌撞击声。
- [ ] 命中或取消后水平速度快速衰减，只保留很短惯性，不会继续顶着目标滑行。
- [ ] 0.5 秒内置冷却从冲锋结束后开始，同一目标命中后 2 秒内不会再次触发冲锋。
