# 英灵召唤器测试清单

推荐使用同目录的 `SUMMONER_TEST_CHECKLIST.html`：它可以直接点击勾选、自动保存在浏览器本地，并导入/导出 JSON 测试结果。本文件用于版本库审阅和故障记录。

## GUI 与物品交互

- [ ] 手持召唤器普通右键打开 GUI；没有装入遗物时仍能正常打开。
- [ ] 打开 GUI 后世界背景像原版物品栏一样变暗，GUI 与槽位坐标不偏移。
- [ ] 除召唤器所在槽位外，玩家物品栏、快捷栏、拖动、Shift 移动均正常。
- [ ] 召唤器所在槽位无法拿走、数字键交换或丢弃。
- [ ] 遗物装入后名称、模型、八项属性、技能和天赋立即出现；取出后立即清空并遣散英灵。
- [ ] 0～4 个天赋按固定顺序从右向左显示，图标与名称/效果对应正确。
- [ ] 技能、天赋、行动模式、警戒状态、经验条、燃料条均有正确悬浮说明。
- [ ] 空燃料输入槽显示燃料说明；槽中有物品时只显示该物品的原版悬浮框。
- [ ] 鼠标拿起燃料、遗物后左键玩家物品栏中的召唤器，会分别放入燃料槽或空遗物槽；冲突/无效物品不变化。普通物品不能进入模块槽，旧存量模块仍可取出。
- [ ] 所有数值使用真实服务端状态，生命/攻击/护甲的小数显示正确。

## 遗物、天赋与成长

- [ ] 创造栏展示的遗物保持未鉴定；真正取入玩家物品栏后才随机初始化一次；`/give` 遗物同样在进入物品栏后初始化。
- [ ] 遗物可能生成 0～4 个天赋，2 个最常见；同一天赋不重复。
- [ ] 坏脾气/慵懒互斥，瘦削/壮硕互斥；“平凡”不生成。
- [ ] 复制遗物保留天赋、等级、经验、技能开关和模式，不会重新随机。
- [ ] `/echo_warrior relic reroll_traits` 只作为开发命令工作。
- [ ] 英灵或主人共同参与击杀会增加遗物经验，不减少玩家经验球。
- [ ] 升级需求为 `15 + 2 × 当前等级`，30 级封顶；满级生命 60、攻击 12（无天赋时）。
- [ ] 升级立即刷新在场英灵属性并播放行动栏提示和玩家升级提示音。

## 燃料与召唤

- [ ] 新召唤器燃料为 0/1000；腐肉 +20，灵魂沙和灵魂土均 +50。
- [ ] 召唤器只要位于玩家物品栏且 GUI 未打开，每 5 tick 最多转化一个燃料物品。
- [ ] 同一召唤器转化燃料时，主手和副手都不会每 5 tick 下沉抽动；真正切换物品或切换到另一只召唤器时仍播放换手动画。
- [ ] 容量不足以容纳完整燃料价值时不消耗物品。
- [ ] GUI 内转化时出现 3～6 个轻微粒子，从输入槽弧线飞向燃料条。
- [ ] 燃料条宽度、粒子遮罩和悬浮数据随真实燃料同步。
- [ ] 召唤基础消耗 100，并正确受坏脾气/慵懒的消耗比例影响；创造模式同样扣除。
- [ ] 前方不安全时会在半径 4 格寻找安全位置；完全无安全位置时不扣燃料。
- [ ] GUI 召唤/收回后保持开启；收回单击立即执行，不再出现二次确认。
- [ ] 服务端确认召唤成功后，青蓝灵魂粒子只在按钮附近向外散开；收回成功后，蓝色火焰只在按钮附近向中心汇聚，不扩展到全屏。
- [ ] 潜行右键在英灵未在场时执行召唤，在场时执行召回；召回不扣燃料，英灵不会因时间自然消失。
- [ ] 英灵脱战 5 秒后每 2 秒恢复 1 点生命，并按实际恢复量扣除燃料；无燃料只停止恢复。

## 模式与战斗边界

- [ ] 跟随模式正常跟随并在过远时安全传送。
- [ ] 等待模式重设当前位置锚点，平时限于 2 格；被推离或战斗结束后能够完整寻路返回，不会只迈一步便停止。主动扫描 6 格，战斗目标离开锚点 8 格后放弃。
- [ ] 闲逛模式重设当前位置锚点，通常停留 2～5 秒后连续走完约 4～8 格的有效路径；不会只迈一步便停止，也不会持续无间隔踱步。
- [ ] 闲逛会选择安全可达的陆地目标，在坡地、台阶和存在障碍的环境中能够失败重试；接近 12～14 格边缘时向锚点偏移，越过 16 格后归位，战斗追击最多 24 格。
- [ ] 闲逛可被战斗、主动技能、玩家互动和浮水正常打断；临时行为结束后短暂停留再继续，旧路径不会覆盖高优先级行为。
- [ ] 三种英灵在跟随、闲逛、归位和游泳时主要看向前进方向，不会持续侧头或回头盯着主人；普通行走侧视约限于头部 15°、瞳孔额外 10°。
- [ ] 行走中的战斗目标、苦力怕、伤害来源和快速接近目标仍能覆盖前进视线；停止移动后约 0.3 秒内自然恢复普通观察与玩家对视。
- [ ] 重复点击当前等待/闲逛模式会重新设置锚点。
- [ ] 主动出击会主动攻击敌对生物并协助主人攻击目标。
- [ ] 被动防御只响应主人/自身受击或主人攻击目标。
- [ ] 和平模式只在自身被直接攻击后短暂自卫，不因主人战斗扩大交战。
- [ ] 普通挥刀只在伤害判定帧仍处于原版近战范围且有视线时命中；起手后拉开距离或隔墙不会隔空受伤。
- [ ] 友军、同主人英灵、主人驯服生物、同队实体和创造/旁观玩家不会被攻击。
- [ ] 三种英灵落入普通河流或深水后都会主动浮向水面，持续完全潜水也不会受到溺水伤害。
- [ ] 跟随模式下把英灵困在水下屋顶或封闭水坑中；约 2 秒后其停止水下战斗并尝试游向主人，持续约 5 秒无有效位移后安全传送到主人附近的干燥地面或水面。
- [ ] 等待与闲逛模式不会因为水域逻辑被强制传回主人；阿兹特克追猎、罗马举盾冲锋和军团永存不会被水下脱困传送中途打断。

## 士兵阵列

- [ ] 技能启用后士兵阵列始终生效，不需要附近存在敌人；可在 GUI 技能栏手动关闭。
- [ ] 自身、主人和同主人英灵获得不叠加的 +2 攻击力。
- [ ] 未持盾时增益显示为无限持续的“举起武器！”状态效果，并使用对应的独立状态效果图标，不出现低持续时间闪烁。
- [ ] 受益者离开 8 格光环范围、禁用技能或来源消失时直接取消状态效果。
- [ ] 普通阵列固定提供不叠加的 +2 攻击。
- [ ] 主人在 8 格内任一只手持盾时，状态效果立即切换为“举起盾牌！”及对应图标；攻击仍只增加 2，主人和军团兵获得 15% 最终伤害减免。
- [ ] 放下或移走盾牌后，状态效果立即切回“举起武器！”，不同时残留两个效果。
- [ ] 光环生效时退出世界再重新进入，不会留下无法清除的无限状态效果；旧版本的“士兵阵列”效果也会在上线时清除。
- [ ] GUI 中士兵阵列技能框保持普通白边，不因光环生效出现黄色外框；举盾冲锋充能数字比上一版向下 1 像素且仍清晰可读。

## 举盾冲锋

- [ ] 初始 3 点充能，每 5 秒恢复 1 点；未召唤或放在容器中也按世界时间恢复。
- [ ] 只对预计约 1 秒内命中主人的敌对投射物或有威胁的起爆苦力怕消耗充能。
- [ ] 投射物按盾面方向反射，伤害保留、归属英灵、不会再次触发拦截。
- [ ] 玩家近期主动攻击的苦力怕不会被该技能错误拦截。
- [ ] 苦力怕被沿“远离主人 70% + 冲锋方向 30%”击退约 5～7 格，引信不重置。
- [ ] 冲锋最多约 1 秒，路径阻塞会取消，不沿途造成伤害，只产生轻微推挤。
- [ ] 图标显示 0～3 充能，恢复过程使用从 12 点方向顺时针的像素遮罩。
- [ ] 冲锋开始后播放并维持举盾动作，命中、超时或取消后才播放收盾动作。
- [ ] 举盾期间头部保持笔直并朝向正前方，不被上半身的 30° 举盾旋转带歪；瞳孔仍能小幅独立观察目标。
- [ ] 冲锋速度按“平稳起步—中段加速—末段收势”变化，不是僵硬的恒速滑行。
- [ ] 冲锋沿途有低频风弹掠过声和少量尾流，命中投射物或苦力怕时播放盾牌撞击声。
- [ ] 命中或取消后水平速度快速衰减，只保留很短惯性，不会继续顶着目标滑行。
- [ ] 0.5 秒内置冷却从冲锋结束后开始，同一目标命中后 2 秒内不会再次触发冲锋。

## 军团永存

- [ ] 6 格内至少 2 个敌人，且主人/英灵近期受击或英灵低于 60% 生命时触发。
- [ ] 同一主人同时只有一个军团兵可进入该技能，冷却 20 秒并按世界时间推进。
- [ ] 12 格内有视线的近战和远程敌人均被嘲讽，头顶持续显示生气粒子。
- [ ] 蓄力期间军团兵头顶持续零星出现生气粒子，沿小型抛物线向上喷出再落下；脚底不再出现触发风爆。
- [ ] 触发后播放并维持举盾动作。
- [ ] 5 秒举盾蓄力期间头部保持正直朝前，瞳孔观察不会带动整颗头偏离盾牌防御方向。
- [ ] 5 秒内军团兵不能移动/攻击，获得 +12 护甲和 100% 击退抗性。
- [ ] 5 秒爆发完成后才播放收盾动作，释放声音为风弹爆发声而非普通爆炸声。
- [ ] 只累计可追溯到敌对实体的减免前原始伤害，不累计环境、友军和技能返还伤害。
- [ ] 结束时 6 格内每个敌人都承受完整累计伤害，且该伤害仍受各目标护甲/常规减伤影响。
- [ ] 击退随累计伤害按平方根增长、随距离衰减，极端伤害产生极端但有限可控的表现。
- [ ] 图标显示顺时针冷却遮罩；蓄力和释放具有低干扰视觉/声音反馈。

## 埃及弓箭手

- [ ] 分别在拉弓早期、中期和满弓前杀死目标：先保持当前弓姿和动作相位 6 tick（约 0.3 秒）搜寻替代目标；有替代目标时保留进度平滑转火，没有替代目标时完成当前安全阶段再自然放弓，不从中途姿势跳到满弓、不永久满弓、不瞬间抽搐，也不射出无目标箭。
- [ ] 连续射击至少 20 次：初次 DRAWBOW→SHOOT 后保持左手举起未拉开的弓；第二次起右手独立从箭袋取箭，左手和弓在箭搭弦前始终停在射后待命姿势，随后双臂直接进入满弓，不闪回首次 DRAWBOW 的起始姿势。从箭袋抽出箭、移动到胸前、搭到弓弦的全过程中，按 GeckoLib Catmull-Rom 曲线以 48 Hz 重烘焙的手持箭始终贴合右手，不出现明显脱手、方向错位或轮次相关差异；轮次之间不闪现待机或双手放下，弓和身体不发生单帧跳变。
- [ ] 在放箭后立即杀死最后一个目标：先停在举弓未拉开的待命姿势，再用约 0.5 秒自然放下左手、右手与弓；有其他目标时不得播放这段收弓。
- [ ] 战斗中 10～20 格且视线通畅时停止导航与残留移动输入，以原地站立射击为主，不发生小幅左右挪动或腿部动画闪烁。
- [ ] 平坦开放地面上，任一近身威胁进入 8 格后，埃及弓箭手保持面向主要目标，但实际位置由世界坐标速度持续朝远离威胁的方向增加距离，而不是相对朝向左右平移；最近威胁退出 10 格后停止风筝。
- [ ] 直后方存在墙体、悬崖、火焰、熔岩或细雪时，风筝才改用安全的斜后方/侧向路线；路线执行期间不按固定周期左右换向。一格高实心方块会立即触发普通后退跳跃，腾空期间继续向后移动并迈上方块；二格墙、无安全落脚面和危险方块不会被穿过。
- [ ] 让一名或多名敌人贴到约 2.6 格内，包括宽碰撞箱的蜘蛛，并分别在 DRAWBOW、SHOOT、举弓待命、远程目标刚死亡或射击间隔边界时逼近：备用近战必须立即取消未完成的远程与 hurt 动作，同时保持面向目标并继续后退求生；让僵尸或蜘蛛直接命中弓箭手后也应在同一服务端 tick 抢占为近战，不能继续站着挨打。等待/闲逛模式下，再让攻击者站在活动锚点边界外但仍能贴身命中，弓箭手依然必须完成自卫近战而不向外追击。完整 20 tick 近战只覆盖上半身，下半身按实际位移播放走路，受伤、重新索敌、射箭和后撤步均不能打断；起手后用击退把双方短暂推至约 2.6～4 格时，只要目标仍可见且可攻击，本次命中仍造成伤害并正常击退。若原目标在伤害帧前死亡，允许在不重播、不延时的前提下仅转移一次到最近合法贴身目标；伤害帧后不得转移。若仍复现，保存日志中的 `[EgyptianArcherMelee]` 行。
- [ ] 在等待或闲逛模式下，把弓箭手和敌人引到活动锚点边界外，再让敌人进入约 4 格或直接命中：同一自卫目标必须贯穿近战、后撤步和落地后的重新瞄准，不得在后撤步中出现 `selected=<敌人>` 但 `resolved=-1`，也不得被普通苦力怕警觉抢走头部。敌人仍在 10 格内时可以反击、后退和原地瞄准；失去视线时不向锚点外追击，退出 10 格后解除自卫并返回活动区域。若仍复现，保存 `[EgyptianArcherSelfDefense]`、`[EgyptianArcherGaze]` 与 `[EgyptianArcherPostCombatGaze]` 行。
- [ ] 贴身求生撤退不受“战车与齐射之魂”开关影响：以基础移速 85% 沿远离 8 格内全部有效近身威胁的反距离加权方向移动，最近实际攻击者权重更高；直线受阻时才尝试稳定斜后方/侧方，跳上一格台阶后继续撤退，真正墙体或卡住后能够重规划。最近威胁达到 4 格后退出贴身求生状态并恢复移动射击/普通风筝。
- [ ] 在单个低威胁敌人、6 格内两名敌人、生命不高于 40%、撤退受阻超过约 0.5 秒及近战动作中再次受击五种场景分别测试：后撤步不得打断当前近战，近战结束后按威胁立即尝试；若已经成功撤到 4 格外则不浪费充能，无安全路径也不扣充能。
- [ ] 当前目标在 8 格外且远程敌人命中英灵时，24 格内伤害来源获得紧急转火；8 格内近身威胁仍具有更高优先级。
- [ ] 同时放置两名同优先级敌人并让它们在 8 格内交替略微靠近：拉弓、放箭和举弓待命期间不因距离排序每 2 tick 来回转头。只有最近实际伤害来源或进入实际近战范围的严格更高威胁可以在 DRAW 阶段抢占；转火不重置取箭/拉弓相位，身体、头和瞳孔平滑转向且未对准前不放箭。进入 SHOOT 后锁定已提交目标直至本次放箭完成；若目标死亡则完成当前释放姿态而不射空箭，再从举弓待命状态索敌。
- [ ] 后撤步起跳到落地严格保持开始时朝向；完整碰撞箱不会穿墙，危险方块/无安全路径时不施放也不消耗充能，路径中途被阻挡时停在最后安全位置。
- [ ] 主动警戒可锁定末影龙；玩家先攻击任一龙体部件后，被动防御也能锁定本体，并向 24 格内最近可见部件射击、实际扣除末影龙生命。
- [ ] 在主动警戒下生成幻翼：幻翼进入 24 格球形射程且有视线时正常锁定和射击；飞到超出实际射程或无视线的高空后立即放弃，不会长期举弓抬头跟随，重新俯冲进入射界后可以再次获取。
- [ ] 叶形箭黄色尾迹、锥锋箭黑色尾迹、普通箭无特殊尾迹；齐射成功时身体周围出现黄色粒子。
