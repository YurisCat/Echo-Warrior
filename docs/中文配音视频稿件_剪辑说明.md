# 中文配音视频稿件：剪辑说明

配音时只读同目录的 `中文配音视频稿件.txt`。该文件是干净正文，每一行对应英文稿的一条叙述，空行用于分隔话题和技能，方便分段录音。

本版以作者提供的早期中文稿为底稿，沿用英文稿的介绍顺序。英文对照来源：`E:/Download-Terminal/TencentDownload/稿子_英文配音稿_中英对照 (1).txt`。

目前只拿到了文字稿，没有英文视频、配音音频或时间码。下表编号对应英文稿的 78 条叙述，不代表视频实际有 78 个镜头；这里只对齐信息出现的顺序，不声称已对齐实际时长。正文录好后，需要在剪辑时间线上校准。

## 先处理这几处

1. 开场只保留模组介绍。早期中文稿的“你将从一枚回声罗盘出发……”是一段完整预告，英文开场没有对应的额外叙述位置，因此把其中的“实体影像、并肩作战”移到了重建英灵的位置，避免合成罗盘的画面已经开始，旁白还在概括玩法。
2. 补回“饰品各有独特效果”和“教程手册”两句。英文稿有这两条叙述，但早期中文稿没有；下载的中英对照 TXT 也没有这两句的中文。如果略过，旁白可能提前进入安装饰品。
3. 天赋介绍保留了中文原稿里“强化英灵，也能帮助主人”的意思。这是比英文稿更详细的一处；如果念不完，优先延长天赋界面展示，或者采用下面的短句，不要让介绍拖到技能开关画面。
4. 关刀和武士的额外数值不全部念进正文。“越战越勇”的低生命减伤、关刀连招受击减冷却，以及“踏込”的免伤、三层充能、闪避回充，都留在下方作可选字幕。英文稿没有逐项解释这些信息，把它们全念进去容易挤到下一个技能的展示。
5. 早期中文稿末尾的玩法总结、燃料说明和军队玩笑没有对应的英文叙述位置。正文直接进入版本信息和告别；原来的内容改写后保存在本文末尾，需要增加或延长一段结尾蒙太奇才能加入。

## 录音与镜头怎么配

- 先按自然语速试录，不要为了填满镜头刻意逐字拖长，也不要为了赶切镜头一直加速。
- 同一段展示内，可以把相邻几句作为一个录音段处理，不必在原英文每句结束的位置都停一下。
- 一个技能介绍结束后，如果画面还在演示它的动作，可以留出一小段游戏声音。要等完整的冲锋、跳劈、举盾反击或拔刀动作结束后再判断是否需要缩短镜头。
- 如果空余明显，先缩短没有新动作和新信息的等待、重复演示或界面停留。保留有信息的完整动作；仍有空余时，再在当前话题内补信息。
- 如果中文念不完，先使用短句或把附加机制改成字幕；需要延长的镜头只延长当前技能，不让旁白跨到下一位英灵。

## 可选字幕：原稿信息保留在这里

这些是中文原稿里有、英文叙述没有逐项展开的信息。主稿没有否定这些机制，只是减少口播密度。若当前画面只展示一个动作、不够时间阅读多条字幕，应只选一条。

| 对应技能 | 可选字幕 |
|---|---|
| 越战越勇 | 生命越低，额外减伤越高。 |
| 关刀连段招式 | 受到近战或投射物伤害时，剩余冷却缩短 0.5 秒。 |
| 踏込 | 最多储存三层充能；成功闪避立即恢复一层。 |
| 踏込 | 冲刺期间免疫普通伤害。 |
| 刺 | 拔刀时，对刺入时命中的目标再次造成高额伤害。 |

“冲刺期间免疫普通伤害”按当前百科表述，避免早期中文稿“免疫所有伤害”的绝对承诺。

## 可选结尾：需要增加画面，不直接读入主稿

如果愿意在日本武士介绍之后、版本信息之前增加一段结尾蒙太奇，可以使用下面这段。对应画面依次为：再次考古、不同遗物天赋、饰品搭配、知识碎片、燃料槽、英灵集结。不需要全部保留，按实际新增画面选择。

> 《英灵回声》的探索不会在第一次召唤后结束。
>
> 每次挖掘，都可能让你找到拥有不同天赋的英灵遗物、作用各异的饰品，或是一段你不曾了解的历史知识。
>
> 召唤英灵需要消耗燃料，脱离战斗后的自然生命恢复，也需要消耗燃料。
>
> 如果准备了足够的燃料和召唤器，你还可以组建一支属于自己的英灵队伍。
>
> 当然，如果你召唤了很多、很多、很多英灵，服务器就可能开始吃不消，腐肉和灵魂沙的期货价格，也许还会跟着上涨。

最后一句是保留原稿风格的玩笑，应配英灵集结或轻松的结束画面；不建议为了填补前面某个短技能镜头，把整段总结移进去。

## 版本卡片与维护范围

配音正文采用“具体游戏版本以下载页面为准”，避免中文录音很快随版本进度过时。若希望更换结尾版本卡片，当前仓库 `PROJECT.md` 记录的组合为：

- Minecraft 26.1.2：Fabric / NeoForge。
- Minecraft 1.21.1：Fabric / NeoForge。
- Minecraft 1.20.1：Fabric / Forge。

这些是仓库记录，未在本任务中联网核验实际下载页面和公开发布状态；最终卡片应与准备宣传的发行文件一致。正文的 Fabric / NeoForge 介绍沿用原视频重点，没有把它写成所有兼容线通用的加载器组合。

本任务只编辑视频配音与剪辑文档，没有改变玩法、控制、数值或开发状态，因此不需要修改 `PROJECT.md`、语言文件或百科条目。正文中的正式名称和机制表述已参照当前 `PROJECT.md`、`docs/localization/TERMINOLOGY.md`、中文语言文件及 `encyclopedia/content/atlas.zh_cn.json`。
