# 日本武士残影修复 CL（2026-08-26）

本次版本集中修复日本武士 2A 残影的透明度与踏込轨迹问题，供模型师进行视觉复测。

## 本次修改

- 溶解残影现在同时具有真实透明度，不再只有“缺块溶解”而剩余部分始终完全不透明。
- 每道残影会从自身初始不透明度开始，随存在时间平滑变淡；先生成的旧残影会先透明、先消失。
- 默认模式继续使用武士原始贴图且不额外附色；青色／金色仍需通过调试指令主动开启。
- 踏込残影改为从武士已经走过的上一服务端位置采样，不再从冲刺后的最新位置生成，因此不应超到本体前方。
- `dash_backward` 的真实后撤残影同步采用已走过位置，保持同一视觉规则。

## 请重点检查

1. 连续触发踏込，逐帧观察是否还有任何残影越过武士本体。
2. 观察一串残影时，确认靠前生成的旧残影比新残影更早变淡、消失。
3. 确认溶解和半透明能同时出现，且甲片、布料、面部与刀身贴图仍可辨认。
4. 分别在白天、夜间和草地等复杂背景测试，确认默认原色残影不会过亮或重新变白。
5. 使用以下指令对比第一阶段、默认 2A 和附色 2A：

```mcfunction
/echo_warrior visual samurai_afterimage_advanced off
/echo_warrior visual samurai_afterimage_advanced on
/echo_warrior visual samurai_afterimage_neutral on
/echo_warrior visual samurai_afterimage_neutral off
```

## 当前仍属已知限制

- 2B 描边仍保持禁用；现有 GeckoLib outline 通道会把整套模型绘制成实心白色剪影。
- 踏込后半段攻击动作与伤害时点仍等待新版动画确认，本次没有调整。
- 本次已通过 Java 25 完整构建，并完成开发客户端资源重载；最终透明度节奏仍以游戏内肉眼测试结果为准。
