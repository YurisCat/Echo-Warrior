Echo Warrior · Artist Toolkit

模型师便携更新与启动工具

不需要安装 Git，也不包含大型离线开发环境。工具包只负责记住现有项目目录、通过本机代理从私有 GitHub 仓库更新，以及调用模型师电脑上已经配置好的 Java 25 启动开发客户端。

!
把整个工具包放在项目目录之外。

推荐放在桌面。第一次双击任意 BAT 时选择一次 Echo Warrior 根目录，工具会记住它。更新前请先启动本机代理并确认 HTTP 代理端口为 127.0.0.1:7897。不要把本工具包解压进 Git 项目内部。

日常优先用安全更新

它只在工作目录完全干净时更新。只要发现未提交的 Blender、Blockbench、贴图或代码文件，就会停下并把文件列表显示出来。

启动代理并关闭 Minecraft

确认本机代理正在运行，HTTP 代理端口为 7897；再正常关闭开发客户端，避免更新过程中仍使用旧资源。

双击安全更新

运行：

安全更新项目.bat

第一次选择项目

在目录窗口中选择包含 .git、gradlew.bat 的 Echo Warrior 根目录。以后不再重复选择。

看到绿色完成提示

BAT 会仅为当前更新窗口设置 HTTP_PROXY 和 HTTPS_PROXY，不会更改系统或 Git 全局代理。首次访问私有仓库时，按 GitHub 登录窗口提示完成授权即可。

如果脚本报告“发现尚未保存到 Git 的文件”，这是保护机制，不是故障。请先把模型交付或提交，再更新。

确定不要当前版本时再强制覆盖

它会先联网取得 GitHub 最新版本，然后自动保存未提交文件和可能被覆盖的本地提交，最后把工作目录切换到远程 main。

启动代理并确认成果已经交付

确认 127.0.0.1:7897 可用。即使工具会自动备份，也不要把它当作正常保存模型的方式。

双击强制覆盖入口

运行：

强制覆盖更新（自动备份）.bat

阅读变更列表

脚本会列出即将移出工作目录的文件。确定继续时，键盘输入大写 COVER 并回车。

保留窗口结果

若显示了 modeler-auto-backup 或 modeler-backup/日期，说明旧内容还有恢复线索。需要恢复时把窗口截图发给项目负责人。

不要连续反复运行强制覆盖。它会移走当前未提交文件；虽然工具先做 Git 备份，但恢复仍需要项目负责人或 AI 协助。

双击编译并启动

启动工具不携带 Java 或 Gradle 离线缓存，会使用项目内已有 Java 25、系统 JAVA_HOME 或系统 PATH 中的 Java 25。

建议先完成更新

日常先运行“安全更新”，确认拿到最新模型接口和资源。

双击启动

运行：

启动开发客户端.bat

等待编译

存在 CATTEST 时会直接进入测试世界；没有时会进入 Minecraft 主菜单。已运行的客户端不会重复启动。

遇到下载或 Java 报错

不要反复关闭窗口。把最后一屏截图发给项目负责人，通常是原有开发环境路径变化或出现了新依赖。

选错项目目录时，双击 重新选择项目目录.bat，重新指定一次即可。
工具包不会自动推送文件，也不会永久修改代理配置。 上次选择的标签页会保存在当前浏览器。
