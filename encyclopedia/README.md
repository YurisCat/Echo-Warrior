# Echo Archive / 回声档案馆

Echo Warrior 的交互式网页版百科。

## 设计

- 左侧是按大分类切换的知识地图，支持拖拽、缩放、搜索与节点定位。
- 右侧保持连续滚动的完整条目，不使用翻页式书本布局。
- 当前条目、文章滚动位置、分类地图视角和双栏宽度会保存在本地浏览器中，刷新后继续上次阅读。
- 分类、节点、坐标、连线与文章位于 `content/atlas.zh_cn.json`，以后可以转换为 Minecraft 原生界面读取的数据。
- 当前网页直接复用模组中人工制作的物品、技能、模式与属性图标。

## 本地运行

Windows 下最简单的方式是在项目根目录双击：

```text
启动本地百科.bat
```

启动器会检查 Node.js 版本、在首次运行时自动安装依赖、启动本地服务并打开浏览器。百科运行期间请保持启动窗口开启。

也可以手动运行：

```text
npm run dev
```

生产构建与内容检查：

```text
npm test
```
