# 英灵回响 · 更新工作间

双击 `index.html`，或运行仓库中的 `tools/windows/Open Update Workboard.bat`。不需要安装依赖、启动服务或联网；将本目录的 HTML、CSS 和两个 JavaScript 文件放在一起即可。

页面参考用户指定的 JustOneButton 人类工作间开发清单的浅色紫色系、分类清单、子步骤和本地保存交互。本页独立实现，没有复制其角色图片、任务或个人进度。

## 使用

- 默认显示 **UI 与交互**，第一项为护甲与武器装备区。另有游戏设计、代码与兼容、美术与音频、测试与发行、社群与平台，共 34 项拆分工作。
- 顶部六张设计便笺记录装备呈现、槽位数量、页面结构、武器规则、友军选项位置和改名入口。所有方案初始均为“待决定”，并不是已批准的游戏规则。
- 任务的**范围**和**状态**独立：可以先记录进度，再决定是否加入本次。整体完成度只统计“本次要做”的任务；子步骤勾完不会自动将整项设为完成。
- 每张卡片支持展开子步骤、记录方案／草稿路径、查看来源和作者回复、跳转关联工作、编辑标题与步骤、改变优先级。新增任务可以删除，原始任务可设置“以后再说”或“暂缓”。
- 分类与筛选一起生效，搜索包含来源 ID、留言摘要和备注。使用左侧把手拖动排序，或用卡片的 ↑ ↓；在筛选中移动时，按当前可见列表寻找相邻任务。
- **导出备份**保存全部任务、排序、勾选、备注和设计便笺为 JSON；**导入备份**验证类型和结构，确认后替换当前工作状态。恢复初始清单也需要确认。
- **导出设计稿说明**生成 Markdown：包含设计便笺、本次选定工作的步骤、备注和来源，以及未选入的候选摘要，可交给后续代码或美术工作使用。
- “已经兑现的愿望”保留 15 组历史结果，不计入本次进度。原始核对见 `docs/research/community-feedback-2026-11-11.md`。

## 保存位置

进度保存在当前浏览器的 `localStorage`，键为 `echo-warrior-update-workboard-v1`。不会写回本目录、修改模组配置、修改 `PROJECT.md` 或发布网站。

换浏览器、移动网页目录、清理站点数据或使用无痕窗口可能无法读取原进度；需要交接或移动时先导出 JSON。保存失败时顶部会显示错误，不会假报成功。若同时打开两份页面发生保存冲突，旧页面暂停自动覆盖，可导出该页面进度或刷新读取另一份。
