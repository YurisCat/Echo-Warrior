# MC 百科本地稿件预览

入口为 [`index.html`](index.html)，也可双击 `tools/windows/Open MCMOD Preview.bat`。无需安装依赖、启动服务器或登录；整个目录可离线打开。

首页按实用工具、英灵遗物、英灵饰品、文明传承、知识碎片、考古方块展示全部 43 件资料。点击图标进入正文，支持名称及注册名搜索、正文目录、同分类前后翻阅和浏览器返回。正文中的已收录物品链接留在本地；“站内原页”明确打开 MC 百科。

## 稿件与显示

- `content.js` 是本工具维护的投稿稿件及元数据。它是一个 JSON 数据对象外加 `window.MCMOD_PREVIEW_DATA = …;` 包装，以支持直接从磁盘打开，避免 `file://` 下读取 JSON 的跨域限制。
- 正文 `html` 保留编辑器使用的 `<p>[h1=获得]</p>` 等标题代码，以及原生 `<ul><li>…</li></ul>` 列表。预览将标题显示为有目录的分节标题；“标题代码”可切换回编辑器中的标记显示。列表标点直接来自稿件，不由页面自动改写。
- 正文不书写普通配方摆放表或“合成用途”清单，配方由站内合成组件展示；也不追加“以上机制以英灵回声 0.2.2 为准。”尾注。获得途径以及知识碎片合并、工艺传承修复等操作规则仍保留。
- `app.js`、`style.css`、`index.html` 负责浏览与排版；`icons/` 是既有人工物品图标的展示副本。页面不调用站点编辑接口，也不自动同步远端资料。
- 此工具近似 MC 百科的资料结构、标题和列表样式，不保证与站方渲染器逐像素一致。正式上传时仍使用站内预览检查一次。
